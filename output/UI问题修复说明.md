## 启动新版与验收

本轮涉及 Python 与启动时内联的 JS，需要重启本地服务；只刷新旧页面不能载入全部修改。关闭原启动终端中的服务（Ctrl+C），再双击仓库根目录的 `run_macos.command`。启动器将选择可用本地端口并打开 Edge，具体地址以启动终端为准。

建议按以下顺序检查：

1. 首页点击探索入口并操作示例按钮；输入目标后生成路线，确认等待阶段和最终预览均可见。
2. 路线页展开长阶段，滚动课程到底；确认概览、保存/打开课程按钮仍可访问；保存并重新打开后展开学习初衷。
3. 工作台选择长标题课程，打开下拉框；滚动正文、使用目录跳转，切换阅读、实践、笔记、参考及拆解步骤。
4. 打开过关检查，选择选项和填写长答案；关闭重开保留草稿，切换课程后不保留旧题，跳过不算掌握。
5. 配置页连续开关已保存连接列表，编辑后点击空白处；确认不会因失焦保存而闪动，主动保存仍可用。
6. 资料库检查空库、单文件、多文件、长文件名；展开技术信息，选中文件阅读，检查上传、预览和资料提问入口。
7. 将窗口调整到约 1440×900、1280×800 和 800px 以下宽度，并检查 125%/150% 浏览器缩放和深色模式下主要操作是否完整可见。

## 后续修正：箭头、列表方向和蓝色描边

依据更新后的笔记，以及 `Pasted image 20261113174820.png`、`Pasted image 20261113174932.png`，本次集中修正模型配置页的三个问题，仅修改前端样式与下拉列表定位脚本。

- **箭头错位：** Gradio 原生箭头外壳带有 `top:50%` 和 `translateY(-50%)`，旧覆盖只改了定位方式，没有清除这些偏移。现在使用同一行的 Flex 居中，并同时重置外壳和 SVG 的位置、偏移、变换和间距；输入区为箭头预留固定宽度。
- **列表向上展开：** Gradio 会比较输入框上下两边的空间，即使下方能放下两条选项，也可能选择向上展开。配置页现在固定在输入框下方、间隔 6px 展开，宽度对齐输入框，最高 320px，剩余空间不足时在列表内部滚动。首次打开时若输入框过于靠近窗口底部，先将输入框滚入视口；页面滚动和窗口缩放时重新测量，避免列表与输入框分离。原生选项选择、搜索、上下键、Enter 和 Escape 处理保留。
- **蓝色描边：** 移除配置页搜索、密钥输入及下拉框的焦点光晕，排除后加载页面样式覆盖早期修复的情况。文本输入以中性加深边框提示焦点；平台选择、按钮和链接保留中性键盘焦点轮廓。高级设置弹层内的下拉框也使用同一规则。
- **列表简化：** 配置页不再显示占据列表第一行的键盘操作提示条，选项直接从第一行开始；长名称正常换行。

本次验证为 **32 项通过，1 项跳过**，覆盖下拉定位、视口边缘、缩放与滚动、首次打开滚入视口、样式更新去重、键盘事件、原生连接组件和既有弹窗逻辑；跳过项需要 Chromium。JS 语法和 Git diff 格式检查通过。定位测试使用 Node 的 DOM/几何替身，不能替代真实浏览器渲染。
