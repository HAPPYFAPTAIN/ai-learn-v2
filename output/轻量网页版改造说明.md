# 课程步骤轻量化改造

日期：2026-11-13。用户已确认：为降低网站服务器负担，移除独立“动手学”，课程内保留文字步骤教学，移除电脑探测、屏幕控制及命令执行。

## 已完成

- 独立“动手学”不再注册页面、导航和事件，也不再随网站加载其专用 JS/CSS。旧功能源码和历史数据保留，不参与本次网站页面注册。
- 课程内保留“拆解步骤”、对应原文、完成标准、预设提示、上下步、用户自行完成记录及当前步骤答疑。
- 拆解前由用户选择 Windows、macOS 或 Linux，模型按所选系统给出说明，不读取服务器系统作为学习者系统。
- 首次拆解不再调用环境探索，正常成功路径只需一次拆解模型调用；网络重试仍由公共模型客户端处理。拆解限制为 4–20 步。
- 按用户、课程、课程内容及所选系统保存拆解结果；重复打开复用结果和步骤进度。旧版电脑辅助缓存不直接复用，首次进入新版会按所选系统重建；原课程正文和课程学习记录不删除。
- 预设提示、翻页、完成标记不调用模型。步骤答疑仅在主动提问时调用；问题最多 1000 字，同一身份请求间隔至少 10 秒，滚动一小时最多 20 次。失败请求也计入已发起请求，刷新和切换课程不会重置额度。
- 答疑只传必要且有长度上限的课程文本和当前步骤，并设置回答长度预算；部分模型的最终预算仍由公共客户端兼容规则调整。
- 课程中的屏幕引导、窗口选择、控件读取、圈选和单次电脑操作入口及回调已移除。
- 工作台“环境配置”改为“学习准备”：展示已有课程清单和可复制的命令示例，用户在自己的电脑操作并自行确认。生成安装方案和执行方案的网页按钮、回调均已移除。
- 正文生成和阅读也不再探测运行电脑，不根据服务器上的软件自动跳过用户的准备步骤。自检记录不代表课程已经验证或掌握。

## 资源变化

首次拆解由“环境探索最多 4 次模型调用 + 拆解 1 次”改为一次拆解调用，命中缓存时不调用。网站不再因这部分功能扫描主机软件、读取桌面或执行用户安装命令。

未做服务器 CPU、内存或多用户容量压测，因此不承诺可支持的同时在线人数。共享模型请求队列和账户系统的服务端改造仍属于后续工作；当前本地模式使用同一本地身份，答疑限额也归属于该身份。

## 验证

192 项相关自动测试通过（182 项功能回归及 10 项模型思考设置测试），包含实际 Gradio 组件/事件注册和进程内事件调用：加载反馈→步骤结果→会话状态；同时覆盖缓存、所选系统、用户归属、自检、限额、错误输入、学习流程和 Mac 兼容回归。

修改过的 JS 通过语法检查；Python 编译和 Git diff 格式检查通过。模型调用由测试替身替代，没有使用真实 Key 产生本轮测试费用。

## 网页生效与验收

本次涉及 Python 和 JS，需要重启网站。启动本机测试服务的自动审批返回 404：`codex-auto-review` 模型不可用，启动命令未执行，当前运行的旧服务尚未更新；未完成 Edge 实际页面验收。

可关闭原网站启动终端，再双击仓库根目录的 `run_macos.command` 启动新版。启动器会打开 Edge，并选择可用的本地端口。启动后验证：

1. 侧栏不再出现独立“动手学”。
2. 进入有正文的课程，选择练习系统，点击“拆解步骤”；可查看步骤、提示和完成标准。
3. 返回全文并再次进入，复用步骤和进度；切换系统后重新生成对应说明。
4. “学习准备”可以阅读清单和自行确认，没有生成安装方案、执行命令或屏幕控制按钮。
5. “问问 AI”返回当前步骤内的解释，过长问题、过快提问及额度用尽时有明确反馈。

账户隔离、服务器密钥存储及其余 UI 问题继续按逐项确认的计划处理。
