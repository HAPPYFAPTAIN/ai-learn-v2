# AI Learn React 前端

按《ai-learn 多租户架构改造规划》搭建的独立 SPA：React 19、TypeScript、Vite、Tailwind 4、React Router、TanStack Query。工程继续使用已有 `learn_web/` 路径，避免另建一份 `web/`。旧 Gradio 代码和发布策略没有改动。

## Mac / Windows / Linux 本地预览

需要 Node 22+。在本目录执行：

```sh
npm ci
npm run dev:demo
```

用电脑上的 Edge 或 Safari 打开 <http://127.0.0.1:5173/>。这是**明确标识的内存演示模式**：不需要数据库、账户登录或 API Key，不访问模型或官网；刷新会重置示例内容。`/?empty=1` 可检查没有学习目标的状态。演示只能通过 `--mode demo` 开启，正常生产构建不会包含演示模块。

测试现有真实 API：先按 `docs/learn-core/ops.md` 准备测试数据库、迁移、API 和 worker，再执行 `npm run dev`。Vite 将 `/api/v2` 代理到 `127.0.0.1:8000`。新客户端使用同源 Cookie，不再保存或透传 URL 里的 ticket。正式后端已适配官网 `learn_entry` 的 GET/204 鉴权协议，要求可信代理密钥、预期账号及同源写入；详见 `docs/learn-core/official-auth.md`，真实官网与入口分流仍待联调，不能用演示认证上线。直接访问未登录的真实 API 会明确提示重新从官网进入。

## 结构

- `src/main.tsx`：路由、按页加载、Query 和会话入口。
- `src/session/`：初始化 `/me`、每 120 秒检查/续期、绑定页面账号、停止过期会话。
- `src/api/schema.d.ts`：从 FastAPI OpenAPI 自动生成，禁止手改。
- `src/api/client.ts`：同源请求、账号头、取消、统一错误处理；写请求和模型请求不自动重试。
- `src/api/jobs.ts`：EventSource、账号参数、断线时每 3 秒查询兜底；结束/卸载/换账号即关闭。
- `src/query.ts`：带账号的缓存键、30 秒新鲜期、无后台定时刷新；会话停止即清空。
- `src/pages/`：九组业务对应十个独立地址（学习首页与路线分开）。
- `src/demo/`：开发专用的内存数据适配器。

页面切换学习计划时清空该页面草稿；未完成的资料索引任务 ID 按账号和计划保存在标签页 sessionStorage，以便刷新后继续检查。它不包含凭据或资料正文。

| 模型设置 | 真实模式读取官网按账号过滤的模型列表，搜索、校验并保存主模型，生成/问答使用该选择；供应商界面仅 demo | 官网真实资格/费用联调；个人 API Key 保管不在范围 |

待迁移能力不会伪装为已成功；此阶段不能代替整站切换验收。真实请求仍使用官网网关，未增加个人 API Key 保存、直连供应商或系统钥匙串功能。完整迁移清单与资源影响见 `docs/learn-core/frontend-framework.md`。

真实 API 模式下，创建学习计划会在同一事务中建立路线生成任务，自动跳转对应工作台；学习工作台的侧栏入口先展示全部计划，选择计划后进入章节目录，再选择章节进入课文。需先在模型设置选择可用主模型，启动 `llm` 队列 worker 并配置可用的官网网关。前端不会自动批量备课，重复提交复用在途任务；页面按任务 id 恢复进度，完成后显示排队、完整模型响应和总耗时。路线生成显示估算进度和剩余时间，采用本账号同模型近期成功任务的耗时中位数，首次参考 45 秒；排队时不承诺剩余时间，保存成功才显示 100%。已有章节不会被路线生成覆盖，教材重新生成需显式勾选替换。内存 demo 不调用模型，也不伪造生成成功。

测验/复习卡同样使用上述任务队列，单次最多 20 题/张；测验范围最多 20 个章节，复习卡每次一个章节。选择题直接判分；其他题型完全匹配时直接判分，其余按旧版规则由模型批改。一次试卷保留一次已完成提交，重试或重复点击返回同一个任务。`POST /quizzes/{id}/submit` 已弃用并改为与 `/grade-jobs` 相同的 202 契约，结果从 `/result` 获取；不会再用字符串不相等直接判错简答题。当前未提供重考入口。FSRS 使用与旧 Linux 运行时相同的纯 Python `fsrs==6.3.1`，不新增服务进程。

当前目标是保留旧用户系统、支持 2–3 人的完整试用版，范围见 `docs/learn-core/internal-beta.md`；当前代码尚未通过完整试用验收。

显式 demo 中的模型设置分上下两区：上方选择已导入供应商和主模型，下方第一项是自定义添加，后面完整迁入旧版 32 个平台预设（加自定义共 33 项），支持搜索和国内/海外/聚合中转/本地分类。`dev:demo` 中点击自定义或预设打开独立供应商弹窗，可添加包含名称、备注、官网链接、地址和模型 ID 的临时配置，并体验主模型切换；切换应用页面保留、刷新重置。示例不代表真实已导入或验证过的账户。API Key 字段始终禁用；正常 API 模式展示实际网关目录并允许保存主模型，不展示示例供应商为真实账户配置。个人密钥管理不在本轮范围。弹窗提供接口地区/服务方案选择，顶部和底部固定、正文单独滚动，支持 Esc、遮罩关闭和焦点恢复。预设地址沿用旧平台目录，模型 ID 可编辑，以供应商实际支持为准。

预设快照位于 `src/models/provider-catalog.json`，不在浏览器运行时依赖旧 Python 模块。更新旧目录后执行 `python scripts/learn_web/sync_providers.py`，用 `--check` 验证全量同步；主模型下拉框继续使用统一网页控件。

供应商品牌图标复用旧版 `learning_ext/assets/vendor/platform-icons/` 的静态 SVG，随前端本地打包，不从第三方网站实时加载。多数图标来自 MIT 许可的 LobeHub Icons；原始来源清单、许可证和声明随构建发布到 `third-party/provider-icons/`。这些是品牌图形资源，并非全部直接下载自品牌官网；自定义入口使用通用标记。

## 持久化问答与学习工具

问答/教练采用请求 UUID、后台任务和现有租户会话表保存；React 只观察任务，刷新不会重新提交。模型等待期间释放业务数据库连接，任务恢复使用已经保存的请求输入；资料可选全部或最多 20 份，引用打开提取文字预览。账号内资料共享，不同账号通过 RLS 和文件目录隔离。

学习工具默认提供分步练习教练，可选择章节；操作由学习者自行完成，用户反馈不会冒充工具验证，也不会自动写成掌握。润色迁移旧版用途提示词和代码/链接/数字保护规则，最多 12000 字，异步处理、原文和结果并列保留，支持刷新恢复和复制；拒绝损坏受保护内容的输出。

## 契约与检查

后端接口变更后，在仓库根目录：

```sh
python scripts/learn_web/export_openapi.py
cd learn_web
npm run api:generate
npm run api:check
npm test
npm run build
npx playwright install chromium
npm run test:browser
LEARN_WEB_TEST_DEMO=1 npm run test:browser
```

`openapi.json` 是 FastAPI 的快照；CI 校验实际 API 和快照一致，检查生成类型、构建、Vitest、Playwright。浏览器测试使用隔离的 HTTP 示例数据，涵盖全部路由、390/1440px、明暗主题、创建计划、笔记、项目切换、复习、测验、错误重试、账号失效和 SSE 重连。它们不是数据库/RLS、真实网关或 Safari 的验收证明。

根目录也可以运行 `scripts/ci-check.sh web`。脚本不安装依赖。代码格式检查：`npm run format:check`。

## 构建与部署评审

```sh
npm run build
# 产物：dist/，默认路径 /official/learn-everything/app/
```

同源部署时 API 默认 `/official/learn-everything/api/v2`；特殊前缀用构建参数 `VITE_API_BASE`（完整 API 前缀）和 `LEARN_WEB_BASE`（SPA 路径）。跨域地址会被拒绝，请使用同源代理。

例如仅测试 API 自带的 `/app` 静态挂载：

```sh
VITE_API_BASE=/api/v2 LEARN_WEB_BASE=/app/ npm run build
```

上线需 nginx 同时设置 SPA 深链接回退、`index.html` 的 `no-store`、哈希静态资源的长期缓存及 API/SSE 的不缓存；当前旧发布包没有加入此 SPA，也没有切换生产入口。
