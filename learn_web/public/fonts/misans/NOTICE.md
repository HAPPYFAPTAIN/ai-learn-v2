# MiSans VF

The WOFF2 files in this directory are the official, unmodified MiSans VF web-font segments published by Xiaomi.

- Source: https://hyperos.mi.com/font/zh/download/
- License: https://hyperos.mi.com/font/zh/download/
- Copyright: Beijing Xiaomi Mobile Software Co., Ltd.
- Segments were selected for Simplified Chinese and Latin; font files were not edited or subsetted.

The application identifies MiSans in its navigation footer and keeps system-font fallbacks.
