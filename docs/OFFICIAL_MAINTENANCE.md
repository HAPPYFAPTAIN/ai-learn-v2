## 首页概览异常的根因

“从这里开始”的编号与标题分行、“接下来”的链接出现默认下划线，可以用未经修复的上游首页组件与 Gradio 4.44.1 复现。相关 CSS 文件存在且已由服务器返回，不是仅凭截图推断的文件漏传。

Gradio 的 `.gradio-container-4-44-1 .prose ol` 设置 `list-style-position: inside`；组件内部标题 `b` 是块级元素，于是编号占一行，标题换到下一行。`.prose a` 的优先级也高于原 `.le-rail-links a`，把 `text-decoration: none` 覆盖为 `underline`。

修复仅提高 `#le-home-rail` 内列表与链接规则的优先级，显式使用外置编号及零项目外边距，不影响课程正文和其他 Markdown。原设计在1800 CSS像素以上显示主栏加概览栏，更窄时概览堆叠；截图物理像素不等于 CSS 视口宽度，不能据此随意修改断点。

`scripts/preview_home_rail.py` 使用真实 `gr.HTML`、首页 HTML 和完整样式管线；`tests/browser/home-rail.spec.mjs` 检查编号与标题顶部一致、链接装饰、断点和溢出。该页面没有用户数据或模型调用，只用于复现，不是正式应用入口。

## 引用图按需加载

`custom_app.py` 在构建应用前安装 `learning_ext.citation_visualization` 的兼容适配。它只替换 Kotaemon 的引用图组件入口，保留原组件接口；实际绘图时才从固定子模块加载原实现及 UMAP。不会修改子模块、运行中的依赖或绘图算法。

原文件 SHA256 在适配层固定；升级子模块后必须审阅并更新摘要，发生漂移时拒绝执行该可选绘图。实现类按进程缓存并由锁合并首次加载；导入失败不缓存成功状态，允许重试。向量模型、问题文本和投影器按调用/组件实例保存，不作为进程共享缓存。首次绘图通过原队列报告准备状态；可选绘图失败保留文字回答与资料引用，并给出提示。

轻量CI覆盖并发加载、失败重试与来源漂移。`tests/test_citation_integration.py` 需在隔离的完整Linux运行时中设置 `LE_TEST_FULL_RUNTIME=1`，验证完整页面构建没有导入UMAP、真实图结果与原算法一致、实例状态独立及失败提示。使用确定性的测试向量和固定UMAP参数，不调用收费模型。性能对比必须使用相同CPU/内存限额，区分新空间、同空间重启与热请求，不能累加嵌套importtime数字。

当前 Gradio、LlamaIndex 的公共类型以及实际使用的 LanceDB 文档存储仍由主流程加载。后续拆分需保持页面组件配置、队列事件与数据库接口兼容；两实例上限下不默认增加额外账号预热进程，避免占满其他用户的名额。

## 历史路线与账号切换

已有路线由个人数据库读取，页面初始化不能把等待或异常画成“没有保存记录”。首页展示读取状态，路线列表、选中项和详情由一个非排队的只读回调恢复；读取异常明确报错，刷新可重试。学习路线为默认可见的主导航入口。模型生成、备课和删除仍按原队列/确认约束执行。

账号级隔离分为两层：服务端按可信官网UID选择独立Unix进程/目录；浏览器把当前页面绑定到打开时的UID，防止共享Cookie被另一标签页更新后，旧页面状态继续操作新账号。同一账号刷新、重新登录和进程回收后的启动应读取原目录，不能重新分配随机用户目录。网页退出和换号不会删除数据库。

排查“记录丢失”先只读核对账号唯一匹配、目录链接、SQLite完整性、项目/节点计数和旧快照，再验证页面回调与网络身份。无法确定归属的旧共享 `default` 数据不得复制给任意账号；数据仍存在时不以恢复备份覆盖当前状态。缺陷与具体账号的脱敏核对证据写入ONES，原始内容不进Git。
