# 2026-11-21 学习交互与布局修复

依据用户本地《AI learning修改.md》及同目录 16 张配图，在 React 新版完成本轮修改。基于已合并 PR #15 的 main（c640972），旧 Gradio 与 kotaemon 未改。

## 逐项原因和实现

| 笔记项 | 原因 | 修改后的行为 |
| --- | --- | --- |
| 1 删除学习计划/路线时闪动 | 删除弹窗嵌在带 hover transform 的卡片中，fixed 定位被卡片建立的包含块限制，移开鼠标后又恢复全屏 | 共用 Dialog 经 React Portal 挂到 body，点击删除只显示一层居中确认框。保留删除范围、不可恢复提示、取消与二次确认；没有执行真实删除 |
| 2 模型供应商编辑与搜索间距 | 编辑动作行只有顶部外边距，和下方搜索框紧贴 | 为供应商动作区补齐底部间距 |
| 3 章节阅读工具空白过多 | 导出按钮独占一行；字号标签/滑块/数值纵向堆叠，整行底部对齐 | 搜索、匹配跳转、字号和导出合并为紧凑工具栏；移动端自动换行 |
| 4 learning-diagram 是什么 | 旧教材提示词要求模型输出结构图 JSON，React 只把这种 fenced block 当代码展示 | 新增本地 SVG 知识结构图渲染器，默认显示节点、箭头与标题，另提供可展开文字关系。限制文本大小、2–10 个节点、18 条连线和 6 层；无效结构显示说明及可展开原文，保留上下文，不执行模型 HTML/SVG |
| 5 学完后去下一节 | 原有按钮只保存 status，缺少后续导航 | 保存成功后显示“前往下一节”；最后一节显示返回目录。刷新已学章节仍能看到入口，不自动生成下一节 |
| 6 返回目录常驻 | 顶栏和返回入口原先随正文滚出视口 | 顶栏改为 sticky；章节页的“返回章节目录”放进顶栏，保留计划切换与主题按钮。沿用草稿离开确认 |
| 7 生成练习 | 原练习页只有任务列表，没有新练习入口 | 增加“生成本节练习”弹窗，默认选择当前章节与实操题型，复用已有 quiz-jobs。用户主动点击才生成，结果保存为测验，完成后可直接“开始作答”；既有任务列表保留 |
| 8 复习优先 | 创建表单一直占据页首，把已有卡片推到下方 | 页首展示待复习卡和复习安排；右上角“新建复习卡”打开原生成表单。弹窗关闭后保留输入，已有生成任务继续跟踪并刷新卡片列表 |
| 9 手动复习卡间距 | 表单标签、输入、按钮缺少分组间距 | 关联章节、问题和答案分别分组，统一弹窗内容与操作区间距，保留未保存草稿确认和提交恢复 |
| 10 测验优先 | 创建表单排在所有已有测验上方 | 页首展示我的测验/答题区；右上角“新建测验”打开生成弹窗。章节范围滚动单独放在 fieldset 内，避免 legend 覆盖滚动首项 |
| 末项 联网查资料 | 资料库只查询已上传文件，没有外部检索入口 | 新增“联网查资料”，输入关键词后可选必应、百度、Google，用户点击后在新标签页搜索；下载的文件可继续上传资料库。当前不是服务器抓取、自动导入或 AI 联网回答 |

## 服务端资源和部署

- 不新增后端接口、迁移、依赖、worker、并发、后台预生成或搜索服务。
- SVG 在浏览器本地绘制，不加载第三方图片或脚本。
- 章节练习复用现有测验任务、队列和额度限制。仅用户主动提交时调用主模型，仍可能产生供应商调用费用；填空/简答/实操批改继续遵循现有规则。
- 资料检索只是外部搜索引擎链接，只发送用户填写的关键词，不自动发送课文、资料内容、账号信息或 Key；不消耗模型额度或服务器搜索资源。
- 发布仍按现有不可变发布流程；本轮不改服务器配置、不访问生产数据。个人 Key 能否导入仍由 PR #15 的运维配置决定，参见 [个人 Key 官网操作单](personal-api-key-production.md)。

## 后续验收顺序

1. 打开学习计划页，点删除后移动鼠标，确认始终只有一个居中弹窗；取消或 Escape 不删除计划。
2. 打开长章节，检查搜索、字号、导出按钮；滚动到底部，确认顶部仍可返回目录。标记学完后点“前往下一节”，最后一节返回目录。
3. 查看包含 `learning-diagram` 的已有教材，确认显示知识点和箭头，手机宽度下仅图内横向滚动；无效 JSON 提示及原文折叠正常。
4. 在章节练习、测验和复习页分别打开生成窗口，确认范围、题型和数量；使用有额度的测试账号主动生成，关闭窗口后等待完成，再检查结果。生成和主观题批改可能消耗真实模型额度。
5. 检查手动复习卡的字段间距、保存和草稿离开确认。资料库输入关键词切换搜索引擎，确认链接打开所选引擎；下载的文件仍由用户手动上传。

生产仍需运维按现有流程构建候选版本、验收和发布，本轮没有修改生产运行目录。
