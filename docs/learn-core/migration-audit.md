## 复用边界

- 提示词、章节结构、路线节点与前置依赖语义、数值章节排序直接移植，并记录旧文件来源。
- 不导入旧 service：它们会带入旧 ORM、Kotaemon/Gradio、本地环境探测、线程和全进程锁。
- 新服务第一个参数为 `Session`，调用者负责事务；模型调用拆为读取、无业务事务等待、写回三段。
- 生成任务落入 Procrastinate 与 `job_progress`；提交与业务任务行使用同一事务，避免队列看不到尚未提交的进度。
- 路线只填充空项目；已有章节不自动覆盖。章节生成按版本比较写回，过期结果丢弃。
- 本轮用户主动点击才生成，不启动批量备课或付费预生成。默认预生成两节仍属于规划中待产品确认的事项。
- 自定义模型演示不升级为个人密钥保管服务。真实模型调用继续走官网网关。

## 本轮首批范围

首批已编写 AI 路线与章节备课的任务/API/React 接入；第二批测验与复习任务已完成本地自动化验证，剩余项以上表为准。
用户随后确定完整试用版必须支持 2–3 人使用，保留旧用户系统，并包含资料库、测验、复习；交付范围以 `internal-beta.md` 为准，不以首批代码冒充完整试用版。
真实模型速度必须用可用的官网测试网关另测；模拟响应耗时不能当成模型性能。

### 首批实现与验证

- 旧版路线提示词、章节教学结构、内容有效性规则和数值章节排序迁入 `learn_core/learning/`，无旧运行时导入；桌面环境检测声明改成网页上的用户自行核实。
- 新增 `POST /projects/{id}/roadmap-jobs`、`POST /nodes/{id}/lesson-jobs`，返回 202；提交队列和进度写入同一事务，重复点击返回同一在途任务。
- 模型输入读取后关闭业务事务；HTTP 调用期间不持有数据库连接。新 worker 调用传官网用户 id，按租户主模型路由，记录事件和用量。后续同步 chat 链路亦已统一身份、模型选择和事务边界。
- 网关传输重试复用事件 id，网络/429/502/503/504 最多两次任务重试（10、40 秒）；400/401/402/403/404 和截断/无效输出不自动重试。402 的全租户后台队列暂停尚未实现，本轮不启用付费预生成。
- 路线不覆盖已有章节；章节生成期间修改或删除，旧结果不会写回。任务完成和结果在同一事务提交，恢复重跑不会重复生成已完成内容。
- 新后端原排期边方向与旧版相反，已统一为“source 依赖 target”；添加数值章节排序。
- 修复空库初始化时 `0005` 重复添加 `original_name` 的问题；独立临时 PostgreSQL 已从空库迁移至 head。
- 71 项后端回归通过（含真实 PostgreSQL、真实 Procrastinate worker、模拟模型 HTTP 响应）；React 的 `scripts/ci-check.sh web`、格式与 OpenAPI 检查结果见本轮交付说明。
- 耗时当前为整次模型响应，不是首字延迟；模拟响应的数值只验证 UI，不是性能结论。

### 第二批实现与验证（2026-11-15）

- 测验和复习卡沿用旧版提示词/数据结构，新增模型输出校验、范围校验与原子保存。题量/卡量限制 1–20，模型异常输出不留半份试卷。
- 批改复用同一持久化任务通道。选择题和完全匹配的答案不调用模型；语义批改沿用旧版填空等价、简答要点和实操步骤规则，严格校验题目 ID、数量及布尔结果。批改结果、逐题点评、用户答案、掌握度与日报指标在同一事务提交。
- 旧 `/submit` 入口统一返回 202 任务，不再同步错误判分。已完成试卷重复提交复用既有结果；当前重考未实现，后续应明确建新答卷，不能静默重复收费。
- `GET /quizzes/{id}/grade-job` 和 `/result` 支持重新打开/刷新恢复状态；查询和任务仍受租户隔离。
- 复习移植 FSRS 6.3.1（旧运行时锁定版本），UTC 排期和日志在调用者事务内保存；行锁 + `expectedReps` 防止新版多窗口重复评分。旧调用方未传计数时保留兼容。
- 掌握度沿用旧版测验 0.4、记忆 0.3、进度 0.3 权重；完成/已掌握章节不因一次错题被静默降级。
- 本地 85 项后端检查通过；前端 14 项单元检查、68 项普通浏览器检查、10 项模型设置演示检查通过。浏览器覆盖生成题目/卡片、批改中刷新、结果恢复、复习排期刷新和 390/1440px；模型 HTTP 使用隔离模拟，不代表真实模型质量或响应速度。
- 该批当时仍缺的资料操作、持久化资料问答、真实模型设置随后已接通，见下方；真实官网联调仍待验收。
