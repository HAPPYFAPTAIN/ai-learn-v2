# React 前端与试用后端衔接

2026-11-15，`codex/react-frontend-framework`。依据用户提供的多租户规划，先完成 2–3 人试用流程，同时保留未来的共享后端结构。完整功能与交付条件见 [internal-beta.md](internal-beta.md)，逐项迁移见 [migration-audit.md](migration-audit.md)。未修改旧 Gradio、`learning_ext/`、`le_platform/`、Kotaemon 或生产发布策略。

## 前端与接口

React 19、Vite/TypeScript、Tailwind 4、React Router、TanStack Query；页面按需加载，绿色主题、明暗模式、自适应表单、统一网页下拉控件，支持 390px 与桌面。生产构建为静态资源，不额外运行 Node 服务。

学习工作台为计划列表 → 章节目录 → 单节学习；首页创建目标时原子提交路线任务并自动跳转，课文/试卷/卡片由用户操作时生成。问答、教练、润色同样进入持久化队列，不自动批量预生成。

`/api/v2` 的 Pydantic/OpenAPI 快照生成 TypeScript 客户端类型，CI 检查漂移。前端 Query 缓存按账号隔离，不定时重取；会话停止时清空缓存、取消请求、丢弃迟到响应。付费写操作不自动重试。

## 账号和任务恢复

`/me` 返回官网复核身份和已实现能力，不含票据/密钥；空间展示仍为 null。正常 API 已按现有官网 GET/204/header 协议复核 learn_entry，并校验可信代理、预期账号和同源写入，见 [official-auth.md](official-auth.md)。真实官网联调尚未完成。

React 每 120 秒复用官网现有续期流程，换账号即停止旧页面。模型设置在真实模式读取网关过滤后的目录，校验并保存 tenant_setting.chat_model；32 个平台预设及自定义弹窗只在 demo 展示元数据，不接受真实个人 API Key。

生成、问答和工具均返回任务编号；页面通过 SSE 观察，断线时每 3 秒查询兜底，结束/离开/换账号关闭。sessionStorage 仅保存按账号/计划隔离的任务编号，不含凭据或正文。服务端历史/在途任务让重新进入仍能恢复，重复 UUID 提交复用原任务。问答与润色先保存不可变模型输入再调用网关。

路线进度每秒在浏览器本地估算，不增加模型请求；按本账号/模型/类型近十条成功任务中位数估时，首次参考 45 秒，排队单独显示。100% 仅表示保存成功。耗时记录为完整模型响应，不是首字延迟。

## 资源边界

- 复用既定的 Postgres、Procrastinate、llm/io worker、共享本机嵌入服务；不创建每账号常驻进程。
- 模型调用和新索引嵌入等待时不占业务数据库连接。长资料解析在 IO worker；单文件 50MB、PDF 200 页、最多百万提取字符，嵌入分批 16 块。
- 上传配额在租户锁下按原件字节计量；当前仍整份读入内存，未完成规划中的“空间预留 + 流式上传 + 悬空清理”全流程，不能声称已达到大并发容量。
- 原件、检索块与向量分开；文件删除与持久化清理任务协调，上传相同内容不被旧清理任务删除。
- SSE 服务端目前每订阅每秒查询一次数据库，LISTEN/NOTIFY 仍待实现；本轮不声称支持 50–200 人。
- 本地试用仅一个模型 worker、一个 IO worker（各并发 1）、一个共享嵌入进程；这是测试起点，不是已测得的线上配置。实际 2–3 人峰值、RSS/CPU、磁盘与失败恢复待实测。
- 新增纯 Python fsrs 6.3.1 与 pypdf 7.1.0；API 不安装 ONNX。嵌入依赖仍独立，新增二进制安装应在仓库外锁版本和校验值后进行。

Markdown 延迟加载、禁原始 HTML，已支持公式、代码高亮和复制；markmap 仅点击后加载。资料默认查看提取文字，PDF 可切换为 pdf.js 原件预览；DOCX 仍提供提取文字和原件下载。供应商图标沿用旧静态 SVG 与许可证，随构建本地发布，不从外站实时读取。

当前生产构建主 JS 约 326KB（gzip 104KB），CSS 约 41KB（gzip 9KB）；Markdown/公式/高亮与导图按需加载并共享部分依赖，以最终构建输出为准；demo 模块被生产构建移除。

### 资料库原件预览与查找

- 资料库新增 TXT/Markdown/PDF/DOCX 类型筛选，与名称搜索组合使用；可按添加时间、名称（自然数字顺序）、文件大小排序。筛选只处理当前已加载清单，不增加服务端请求；总数是文件数量，不是账号空间配额。
- PDF 默认仍展示提取文字。点击“PDF 原件”才加载 PDF.js 6.5.438 legacy 构建和对应 worker，复用已有鉴权下载 API，不添加后端转换服务。支持逐页浏览、页码跳转、50%–200% 相对适应宽度缩放、重试和原件下载；文本复制与查找使用提取文字。
- 预览限制为 20 MB、200 页，每次绘制一页，Canvas 最多 800 万像素，最大边 8192 像素。超过预览限制、加密或损坏的 PDF 保留提取文字和下载入口；这些限制不改变原有 50 MB 上传上限。未知文件大小时仍需获取原件后才能判定大小，当前并非流式限长下载。
- 关闭、切回文字或账号停止时取消原件请求，卸载时销毁 PDF 文档和 worker；切页时取消旧绘制，完成后释放当前页缓存。只渲染画布，不启用 PDF 表单/XFA、脚本执行和交互链接；原件保留自身配色。
- `predev`、`predev:demo`、`prebuild` 自动准备配套字体、CMap、WASM、ICC 和许可证。约 4.3 MB 的辅助静态数据在构建目录中，不按用户复制、不常驻服务器内存，仅按页面需要请求。PDF 预览 JS 约 562 KB（gzip 172 KB），parser worker 约 1.3 MB，均在选择原件预览后加载；首页主脚本约 326 KB 不变。
- 上线静态资源必须包含 `dist/pdfjs-assets/` 和 worker，使用实际子路径部署；资源目录及各子目录许可证须一同保留，不能只上传主 JS。旧 Gradio 发布策略保持原样，React SPA 尚未纳入生产候选包。

### 资料批量操作与账号衔接

- 资料库支持逐份选择、选择当前筛选结果、清除选择与批量删除；隐藏在筛选之外的已选资料有明确提示，确认弹窗列出完整清单。每批最多 50 份，逐个调用现有 DELETE，不增加后台批量服务或并行删除压力。

## 2026-11-17：未保存提醒与异常写入恢复

`DraftProtection` 在应用中集中注册表单的 dirty/pending 状态，使用一个 React Router blocker，覆盖笔记、笔记编辑、批注、问答/教练输入和手动复习卡。路由、计划/章节切换、章节内容标签切换及关闭编辑弹窗前可选择继续编辑或放弃；请求仍在进行时提醒服务端可能已经接收。阻塞期间保存成功且草稿清空后可继续原导航。账号会话停止时沿用立即卸载/清缓存，不能为草稿保留旧账号页面。

刷新/关闭标签页由 `beforeunload` 请求浏览器原生提醒，浏览器可限制提醒；确认刷新、强制退出或崩溃仍可能丢失输入。正文只在组件内存中，保护登记表仅存标记和标签，不把正文写入 localStorage/sessionStorage。它不是自动保存或跨设备草稿恢复。

API 客户端把写请求的超时、网络异常、5xx 和成功响应无法解析标为结果不确定。`WriteRecovery` 要求先通过现有 GET 核对记录；读取失败不开放重试，读取成功后用户还需明确允许，再点击原提交按钮。不会自动重发。笔记/批注/手动卡片只有在可靠的原列表基线及精确匹配时才自动确认新记录，旧有同文记录不作为成功证据；核对时新输入不会被清空。列表没有记录并不保证未保存，跨客户端并发下可靠幂等仍依赖后端。

问答沿用 requestId，同一提交签名的明确重试继续用原编号；可先刷新历史及活动任务。网络横幅只监听浏览器 online/offline 事件，无后台轮询，也不把 online 等同于服务正常。

弹窗按栈管理焦点、Esc 和滚动锁，确认层显示时下层 inert。自定义下拉展开主动聚焦，Esc 收起菜单后由弹窗尊重 defaultPrevented，避免 Safari 中连带关闭弹窗。报告打印直接在点击回调中调用 window.print，保持 Safari 的用户激活；打印范围仍限定阶段报告和日报。
