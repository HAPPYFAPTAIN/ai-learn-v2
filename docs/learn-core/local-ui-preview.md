# 本地界面预览

本入口用于检查 React UI，使用临时示例数据。刷新页面会重置本次修改，不连接真实账号或模型、不产生模型费用。上传进度为演示，不代表网络或服务器性能；真实模式读取浏览器上传字节事件。

## 启动

在终端运行（本机已准备依赖）：

```sh
cd '/Users/tyy/.codex/worktrees/online-pr-scope/learn-everything'
npm --prefix learn_web run dev:demo -- --port 5173
```

保持终端运行，在 Edge 或 Safari 地址栏输入 <http://127.0.0.1:5173/>。如果提示端口占用，先检查浏览器能否打开已有页面，避免重复启动。关闭服务可在该终端按 `Ctrl+C`。这是开发命令，不是官网发布或桌面打包入口。

## 资料与基础学习检查

1. **上传进度**：进入 [资料库](http://127.0.0.1:5173/library)，选择一份无敏感信息的 TXT 文件，观察发送进度、等待确认、已确认与索引状态；也可在传输期间点取消。多选两三份文件时先显示清单，确认后逐份上传并索引，可点“停止后续上传”后再手动继续；每批最多 10 份/100 MB。文件只在此演示页面内模拟添加，不发给服务器。
2. **看板图表**：进入 [学习看板](http://127.0.0.1:5173/dashboard)，切换近 7/30 天、学习时长/复习卡片/推进章节，点击柱形查看详情，展开数据表；试试窄窗口和深色主题。缺失日期明确显示“暂无日报记录”。
3. **课文批注**：进入 [示例章节](http://127.0.0.1:5173/study?project=1&chapter=11)，选中正文的一段文字，点击“为所选文字添加批注”，输入并保存。在“本章批注”试用编辑、定位原文和删除；切换页面再回来仍可看到批注，整页刷新则重置。

首次启动若直接链接返回首页，可从侧栏进入对应页面，选择“Python 从入门到实践”及第一节课。

## 六项新增功能体验

1. **测验**：到 [查漏测验](http://127.0.0.1:5173/quiz)，选已有卷或生成演示试卷；用题号导航跳转，故意漏答后提交，完成后看解析和“仅查看错题”。演示卷可能为简答题；点选选择题另由隔离浏览器回归覆盖，不代表真实模型出题质量。
2. **笔记与导出**：到 [示例章节](http://127.0.0.1:5173/study?project=1&chapter=11)，在“内容”导出本节课文；切“笔记”保存、编辑或删除记录，用章节/类型/搜索筛选后“导出当前笔记”。导出仅包含当前筛选结果。
3. **手动复习卡**：到 [间隔复习](http://127.0.0.1:5173/review)，“手动添加复习卡”，填写问题/答案并可关联章节；保存后试用排期列表的搜索/章节/状态/排序，以及上方翻面评分。
4. **阶段报告**：到 [学习看板](http://127.0.0.1:5173/dashboard)，在“学习记录”输入日期或选近7/30天，检查阶段合计；导出 CSV/JSON，点击打印并在浏览器中预览或另存 PDF。
5. **阅读工具**：在课文展开目录、点击标题定位，搜索正文并切换上/下一处；拖动字号。选中正文保存批注后打开“显示批注高亮”，可收起批注列表继续阅读。字号和高亮偏好刷新保留，演示笔记数据仍会重置。

将窗口缩到手机宽度，可检查连续下拉框展开与弹窗布局；切换深色主题检查阅读高亮。修改已落在本地代码中；实际持久化和真实多账号权限仍须接入服务端验收。


## 未保存提醒与网络恢复体验

1. 在示例章节的“笔记”输入内容，切换“内容”、返回目录、点其他页面或浏览器返回。选择“继续编辑”应保留输入；选择“放弃未保存内容”才离开。保存成功后正常切换不应提醒。
2. 在已有笔记点编辑，修改内容后关闭；确认弹窗中按 Esc 应回到仍有内容的编辑框。手动复习卡的取消/关闭也有同样保护。在卡片弹窗展开关联章节，第一次 Esc 只收起下拉框，第二次才询问离开。
3. 问答/教练输入和选区批注也受保护。刷新或关闭标签页时，浏览器可能显示自身提醒；确认刷新后演示数据和未保存输入会重置。崩溃或强制退出无法保证恢复，正文不写浏览器存储。
4. 网络恢复提示不会自动发送输入。真正的超时、服务端已保存但响应丢失、核对失败和显式重试由隔离接口回归覆盖，demo 不模拟真实 API 故障或模型费用。

2026-11-17 原生 Safari 已体验：笔记未保存提醒/继续编辑/保存后切换、课文搜索高亮/目录/定位、自定义下拉 Esc、卡片嵌套确认与取消保留、报告打印预览并取消。Safari 下载已触发浏览器权限提示，自动审批拒绝授权；用户选择跳过，因此未验证下载落盘，也未修改权限设置。Edge 使用已安装的 msedge 通道跑核心交互自动检查；具体次数见 frontend-framework.md 的最终检查。它们都是临时演示/隔离接口，不能代表真实线上多人验收。

开发者可用本机已安装的 Edge 重跑核心流程（需依赖已就绪，测试端口 5174 空闲）：

```sh

```

未设置 `LEARN_WEB_BROWSER_CHANNEL` 时继续使用默认 Chromium，不改变 CI 默认浏览器。Safari 实机体验需在 Safari 打开上述演示地址；本轮未安装 WebKit 测试运行时或开启 Safari 远程自动化。
